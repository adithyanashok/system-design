# System Design Notes

A beginner-friendly, practical guide to System Design, starting from the fundamentals and gradually progressing toward designing large-scale, distributed systems.

The goal of this repository is to understand why system-design concepts exist, what problems they solve, how they work, and when to use them rather than simply memorizing definitions.

## 📚 Learning Path

The topics are organized from fundamentals → infrastructure → distributed systems → real-world system design.

## 🎯 Learning Approach

For every concept, I try to understand:

1. **What is it?**
2. **What problem does it solve?**
3. **How does it work?**
4. **Why do we need it?**
5. **Where is it used in real systems?**
6. **What are the advantages and disadvantages?**
7. **What are the trade-offs?**
8. **What are the alternatives?**
